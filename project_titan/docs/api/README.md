# Project TITAN - Public API & Contract Specifications

This directory contains formal technical specifications for public package contracts, repository interfaces, AI provider contracts, and dataset importer schemas.

## Specifications
- **AI Contracts**: `AIProvider`, `LearningCoach`
- **Repository Contracts**: `PyqRepository`, `AnalyticsRepository`, `BookmarkRepository`, `RevisionRepository`
- **Engine Contracts**: `RevisionStrategy`, `DatasetImporter`, `SearchEngine`
