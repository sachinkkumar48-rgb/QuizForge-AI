# Git Workflow

Every completed task:

* `git add`
* `git commit`
* `git push`

# Coding Rules

* Never rewrite completed functionality without approval.
* Maximum three source files modified per implementation task.
* Never modify unrelated files.
* Preserve backward compatibility.
* Small focused functions.
* Environment variables for secrets.
* Always use verified native tools and avoid invoking unconfigured or denied MCP tools.


# Testing

* New functionality requires tests.
* Existing tests must continue passing.
* Prefer targeted tests.

# Branch Strategy

* `main` — Stable Releases
* `develop` — Integration
* `feature/*` — Feature Development
* `hotfix/*` — Production Fixes
