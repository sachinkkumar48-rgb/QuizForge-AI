# QuizForge AI Rules

1. Never change the existing architecture.
2. Keep using:
   UI → Controller → Repository → Services.
3. Keep using Gemini REST API.
4. Never migrate to Riverpod, Bloc, GetX or Provider.
5. Never rename public classes without approval.
6. Never add new dependencies without approval.
7. Always run dart format after modifying code.
8. Always run flutter analyze before finishing.
9. Fix every analyzer warning and error.
10. Preserve Material 3 UI.
11. Prefer editing existing files over creating new ones.
12. Ask before deleting any file.
